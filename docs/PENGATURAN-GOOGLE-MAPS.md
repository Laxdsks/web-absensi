# Mengaktifkan Google Maps

Peta titik dasar tetap dapat dibuka ketika online. Untuk rute dan panorama resmi di jendela aplikasi, pemilik perlu menyiapkan kunci Google Maps miliknya. Kode tidak memakai kunci milik pihak lain dan tidak mengisi titik awal dengan perkiraan berdasarkan IP.

1. Buka [Google Cloud Console](https://console.cloud.google.com/projectselector2/home/dashboard?createNewProject=true) pada akun pemilik proyek dan buat/pilih proyek Maps. Login Google dilakukan oleh pemilik akun; tidak perlu membagikan kata sandi kepada AI.
2. Aktifkan [**Maps Embed API**](https://console.cloud.google.com/apis/library/maps-embed-backend.googleapis.com) untuk peta, rute, dan Street View. Untuk mode gratis, cukup Maps Embed API; layanan tambahan tidak perlu diaktifkan. Selesaikan pengaturan akun/billing apabila diminta Google.
3. Buat API key dengan pembatasan aplikasi **Websites / HTTP referrers**, izinkan `https://datasiswasekolah.42web.io/*`, lalu batasi API hanya ke **Maps Embed API**.
4. Masuk ke website sebagai administrator. Buka **Tampilan → Google Maps → Belum punya kunci? Mulai di sini** untuk tautan langkah resmi dan tombol salin pembatasan domain. Tempel kunci pada kolom pengaturan, lalu **Simpan pengaturan peta**. Kunci tidak perlu dikirim melalui chat.
5. Tekan **Uji peta**. Pilih **Peta**, **Rute**, lalu **360°**. Jendela ini memakai contoh koordinat Dompu, bukan posisi mahasiswa, dan tidak mengubah absensi. Periksa keluaran Google di dalam jendela: tersimpannya kunci atau selesainya iframe memuat belum membuktikan API aktif. Bila gagal, periksa pesan Google, API yang diaktifkan, akun penagihan, dan pembatasan domain.
6. Buka pin mahasiswa dan izinkan lokasi perangkat dosen. Setelah GPS diizinkan dan cukup akurat, jalur ke mahasiswa otomatis ditampilkan. Tombol utama **Lihat jalan ke mahasiswa** meminta GPS baru bila ingin mencoba ulang. **Cara pergi** memilih kendaraan atau jalan kaki; Google menampilkan jarak jalan dan estimasi waktu. Posisi dosen diperbarui selama peta terbuka; watcher berhenti ketika peta ditutup, tab disembunyikan atau offline. Gunakan **Perbarui lokasi saya** untuk mencoba ulang GPS. Tidak ada isian lintang/bujur atau pilihan lokasi awal manual. Untuk tujuan lain, buka **Tujuan lain (opsional)** lalu isi **Cari tujuan lain** dengan nama tempat beserta kota atau alamat lengkap, tekan **Cari di peta**, lalu **Lihat jalan ke tujuan ini**. Rute mengikuti teks tujuan yang dikonfirmasi pengguna. **Lokasi target (mahasiswa)** mengembalikan pilihan ke rekaman saat mahasiswa mengirim absensi, bukan lokasi langsung mahasiswa.
7. Tekan **360° · Street View** untuk panorama di jendela yang sama. Aplikasi mencari panorama luar ruangan terdekat dalam radius 500 m dari koordinat absen. Koordinat mahasiswa tidak berubah; foto panorama dapat berada di jalan terdekat, bukan tepat pada titik mahasiswa. Hasil tetap mengikuti cakupan Street View Google. Mode layar penuh memperbesar jendela aplikasi.

Kunci disimpan di database hosting, bukan di kode repository. Administrator juga dapat memakai variabel lingkungan `GOOGLE_MAPS_BROWSER_KEY` bila hosting mendukungnya; variabel tersebut memiliki prioritas atas pengaturan database. Kunci browser Maps memang dikirim ke Google melalui browser, sehingga pembatasan domain dan API tetap perlu diterapkan.

Maps Embed API tersedia tanpa biaya pemakaian dan memerlukan kunci API. Google dapat meminta pengaturan akun penagihan saat penyiapan; periksa ketentuannya jika diminta. Maps JavaScript API/Geocoding API adalah layanan terpisah yang dapat berbiaya. Kolom **Layanan tambahan → Kunci Maps JavaScript opsional** secara bawaan kosong. Pada kondisi ini aplikasi tidak memuat JavaScript Maps atau meminta geocoding; rute memakai GPS perangkat dosen dan alamat dapat dibaca di dalam peta Embed. Pencarian nama/alamat memakai mode Search dari Maps Embed API yang sama. Bila pemilik secara khusus memilih layanan tambahan, aktifkan API yang diperlukan dan simpan kunci terpisah dengan pembatasan domain/API yang sesuai pada kolom opsional tersebut. Variabel `GOOGLE_MAPS_JAVASCRIPT_BROWSER_KEY` dapat dipakai bila hosting mendukungnya. Jangan menambahkan layanan berbayar pada kunci Embed. Lihat [petunjuk resmi Google](https://developers.google.com/maps/documentation/embed/quickstart) dan [biaya Maps Embed API](https://developers.google.com/maps/documentation/embed/usage-and-billing).

Dokumentasi peta: https://developers.google.com/maps/documentation/embed/embedding-map

Tes otomatis memeriksa koordinat, URL API resmi, izin GPS, pencarian tujuan, mode layar penuh, dan kondisi offline dengan layanan Google yang disimulasikan. Pengujian Google yang sesungguhnya memerlukan kunci aktif dan jaringan yang dapat mengakses Google; hasil simulasi tidak membuktikan status layanan Google atau cakupan panorama suatu lokasi.

Dosen terautentikasi membaca konfigurasi peta dari server; perubahan kunci hanya diizinkan untuk administrator. Penggunaan peta tidak memerlukan login TinyFish atau Google Cloud pada perangkat dosen, dan tidak menggunakan kredit TinyFish. Peta tetap memerlukan internet, hosting/API yang aktif, dan kunci valid; layanan pihak ketiga tidak dapat dijamin tersedia selamanya.

Pemeriksaan langsung 22 Oktober 2026: konfigurasi Embed tersimpan pada server, kolom Maps JavaScript tetap kosong, dan peta serta rute contoh Dompu berhasil dimuat di jendela web (rute 2,2 km / sekitar 5 menit). Radius Street View bawaan Google 50 m menghasilkan bidang hitam pada titik contoh; pencarian `radius=500&source=outdoor` menampilkan panorama Jalan Kakatua, Dompu. [Bukti pengujian langsung](https://github.com/Laxdsks/web-absensi/actions/runs/39736477065). Kunci tidak disalin ke repository atau laporan.

Pembaruan rute GPS dibatasi saat berpindah setidaknya 30 m dan berselang 15 detik untuk menghindari pemuatan iframe akibat jitter. Pergantian pertemuan atau jenis perjalanan tetap memperbarui rute. GPS yang terlalu kasar, kedaluwarsa, atau lebih dari 100 km tidak diam-diam dijadikan asal rute. Tidak ada layanan Routes/Places berbayar baru yang diaktifkan oleh rute otomatis.

## Memilih tempat sebagai tujuan

Mode Embed menyediakan pencarian nama/alamat dan Directions di iframe Google yang sama. Jalur biru, jarak, serta durasi berasal dari Google; aplikasi tidak menebak durasi dari jarak lurus dan tidak membaca isi iframe lintas origin. Jam/hari/menit ditampilkan sesuai hasil dan format Google. Nama yang ambigu harus dilengkapi kota atau alamat agar pengguna dapat memeriksa tujuan pada peta.

Klik ikon/nama tempat pada peta JavaScript menampilkan **Rute ke sini**. Tombol ini meneruskan koordinat tempat ke Directions Embed, sehingga tidak memerlukan layanan Routes API baru. Penanda mahasiswa juga memiliki tombol **Rute ke mahasiswa**. Nama/foto tambahan berasal dari Places API (New); jika detail gagal, koordinat tempat yang diklik tetap dapat digunakan tanpa menebak nama bisnis. Peta interaktif memerlukan Maps JavaScript API yang diaktifkan pada proyek pemilik; nama/foto memakai Places. Layanan tersebut memiliki kuota dan kemungkinan biaya, bukan gratis permanen tanpa batas. Kode tidak mengaktifkan API atau billing di Google Cloud, tidak menambahkan key, dan tidak memperluas pembatasan key Embed. Sambungan JavaScript yang kosong tetap kosong.

Uji lokal `location-route.test.cjs` mencakup penghapusan kontrol awal manual, GPS kasar/dekat/jauh, urutan dosen ke tujuan, Search/Directions, perubahan moda dan GPS tanpa mengganti tujuan, perlindungan callback GPS terlambat, kembali ke mahasiswa, reset, Street View, tampilan HP, offline, serta penghentian watcher. `map-place-explorer.test.cjs` memakai respons Google tiruan untuk pilihan tempat/jalan, foto, panorama, dan tombol rute. Tes simulasi tidak membuktikan key Google tambahan aktif.
