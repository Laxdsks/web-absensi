# Unduhan aplikasi mahasiswa

Bagian **Unduh & bagikan Presen Go** pada beranda menyediakan unduhan APK, salin tautan, WhatsApp, lembar berbagi perangkat, dan pemilihan APK lokal untuk berbagi file. File tidak diunggah ke server. Jika berbagi file tidak didukung, pengguna diarahkan melampirkan APK unduhan melalui aplikasi pesan.

Alamat tetap: https://github.com/Laxdsks/web-absensi/releases/download/presen-go-current/Presen-Go.apk

Workflow `student-current.yml` memperbarui aset ini hanya setelah APK bertanda tangan lulus verifikasi. Saat menaikkan versi APK, pertahankan nama aset rolling **Presen-Go.apk**; salin dari installer versi baru yang sama dengan rilis terverifikasi. Rilis bernomor tetap tersedia sebagai arsip. Rilis rolling ditandai prerelease agar tidak mengganti rilis utama repositori secara otomatis.

Panduan instalasi/penggunaan tersedia dalam panduan interaktif beranda dan halaman publik `app/panduan-mahasiswa.html` yang dapat dibuka tanpa akun dosen. Berbagi tautan juga menyertakan alamat panduan tersebut.
